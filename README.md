# John S. Adjim — Professional Portfolio

A responsive, single-page static professional portfolio. No build step or API keys required.

## Deploy with GitHub and Vercel

1. Create a new GitHub repository (for example, `john-adjim-portfolio`).
2. Upload `index.html` and `README.md` at the repository root.
3. In Vercel, select **Add New → Project**, import your GitHub repository, and deploy.
4. Select **Framework Preset: Other** if prompted. No build command is needed; output directory is the repository root.

## Edit

Update the text in `index.html` with your preferred project links, verified credentials, and any portfolio photos. The site works without a backend.
